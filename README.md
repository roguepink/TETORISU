# TETORISU（テトリス）

**テトリス × ぷよぷよ × 横スクロールシューティング**

かわいい飛行機に乗って、テトロミノ型の武器でぷよ型の敵を打ち抜く爽快アクション STG です。
同じ色のぷよをまとめてポップさせると **れんさ** が起こり、スコアもフィーバーゲージもぐんぐん伸びます。

ライブラリ不使用・HTML5 Canvas 製。`index.html` をブラウザで開くだけで遊べます。

## あそびかた

```
git clone <このリポジトリ>
cd TETORISU
# そのまま index.html をダブルクリック、または
npx serve .      # http://localhost:3000
```

## ゲームシステム

### れんさ（連鎖）
ぷよを倒すと、近くにいる **同じ色** のぷよがつられてポップします。ポップしたぷよの近くにさらに同じ色がいれば連鎖はどこまでも続き、スコア倍率は 2 倍 → 4 倍 → 8 倍…と増えます。
別の色のぷよやボスには連鎖の衝撃波でダメージが入ります。レインボーぷよはどの色ともつながります。

### フィーバー
ぷよをポップするとフィーバーゲージがたまり、満タンで **FEVER** 発動。9 秒間、色に関係なくすべてのぷよが連鎖し、攻撃力と連射速度もアップします。

### ボム「LINE CLEAR」
画面いっぱいにテトリスのブロックが積み上がり、一気にライン消し！ 画面上の敵をすべてポップさせ、敵弾を消します。

### チャージショット
チャージキーを長押しして離すと、現在の武器の巨大テトロミノを発射。貫通しながら敵をなぎはらいます。

## 武器（10 種 × Lv1〜5）

| ミノ | 名前 | 特徴 |
| --- | --- | --- |
| I | ラインレーザー | まっすぐ貫通。Lv5 でレーザー連射 |
| O | ヘビーブロック | 重い一撃＋着弾爆発 |
| T | トライスプレッド | 3〜7 方向に広がる（初期武器） |
| S | ウェーブ | うねって広範囲をカバー |
| Z | リコシェ | 画面上下で跳ね返り、跳ねるほど強化 |
| J | ホーミング | 敵を追尾する誘導ミノ |
| L | シャッター | 着弾するとミノが四方に飛び散る |
| ● | マシンガン | 超高速連射 |
| ✚ | スピンクロス | 回転しながら敵をなぎはらう貫通弾 |
| 🌈 | テトロレイン | 空からテトロミノが降りそそぐ |

武器アイテムを取ると新しい武器を入手、同じ武器を取るとレベルアップ。入手した武器は Q / E でいつでも切り替えられます。
さらに **オプション**（お供ミノ）、**リアショット**、**ミサイル**、**ワイドショット** などの補助装備も。

ふわふわ漂うぷよ、テトロミノの形で編隊を組むぷよ、弾を吐くぷよ、倒すと分裂する大きなぷよ、突進ぷよ、ぐるぐる回るぷよ、壁になるぷよ、上下にバウンドするぷよ、追いかけてくるぷよ、天井や床に生えるタレットぷよ、灰色のおじゃまぷよ、レインボーぷよ、アイテムを運ぶ風船ぷよ……
